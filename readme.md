# Nimble Eye

Application web fullstack dédiée à la comparaison des prix des caisses Counter-Strike 2 sur différentes plateformes.

## Présentation

Nimble Eye a pour objectif de comparer les prix des caisses CS2 sur plusieurs plateformes afin d'identifier les différences de prix et les opportunités potentielles du marché.

Le projet vise également à intégrer des analyses statistiques pour évaluer la rentabilité théorique de l'ouverture des caisses.

## Fonctionnalités envisagées

- Comparaison des prix des caisses entre plusieurs plateformes.
- Identification de la plateforme proposant le meilleur prix.
- Suivi de l'évolution des prix.
- Analyse statistique de la rentabilité potentielle des caisses.
- Identification d'opportunités potentielles d'achat-revente.
